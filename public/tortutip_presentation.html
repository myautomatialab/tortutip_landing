Arquitectura

Clean Architecture. Claro que sí... ¿en Flutter?

En iOS ya la conocía. En Flutter era otro idioma. Configuración, dependencias, inyecciones, tests... y el reloj corriendo.

Presentation layer
Screens · Blocs · Widgets — solo UI, nunca lógica
Domain layer
Entities · Use Cases · Repositories — Dart puro
Data layer
Data sources · Models · Repository implementations
